# Loom WebUI

Web frontend for Loom, built with React + TypeScript + Vite.

## Directory Structure

```
webui/
├── app.py              # Python entry — re-exports FastAPI app, mounts dist/ in production
├── frontend/           # Vite project
│   ├── index.html
│   ├── package.json
│   ├── vite.config.ts
│   └── src/
│       ├── main.tsx            # App entry point
│       ├── App.tsx             # Root component
│       ├── components/         # UI components
│       │   ├── KanbanBoard.tsx # Kanban board view
│       │   ├── Column.tsx      # Board columns (new / waiting / done / dismissed)
│       │   ├── EnvelopeCard.tsx
│       │   ├── EnvelopeDetail.tsx
│       │   ├── EnvelopeDrawer.tsx
│       │   ├── Sidebar.tsx     # Left sidebar (source filters)
│       │   ├── StatusBar.tsx   # Bottom status bar
│       │   └── ui/             # shadcn/ui primitives
│       └── lib/
│           ├── api.ts          # API client (fetch wrapper)
│           ├── types.ts        # TypeScript type definitions
│           ├── settings.ts     # Frontend settings
│           └── utils.ts        # Utility functions
└── dist/               # Build output (gitignored, generated by vite build)
```

## Development

Frontend and daemon run separately. The Vite dev server proxies `/api` requests to the daemon automatically.

```bash
# Terminal 1: start the daemon (serves the API)
loom daemon --foreground

# Terminal 2: start the frontend dev server
cd loom/webui/frontend
npm install
npm run dev
```

Open http://localhost:5173. All `/api/*` requests are proxied to `http://127.0.0.1:8732` via Vite.

## Production

Build the frontend and let the daemon serve it directly:

```bash
cd loom/webui/frontend
npm run build    # outputs to webui/dist/

# Start the daemon — auto-detects dist/ and mounts static files
loom daemon --foreground
```

Visit http://127.0.0.1:8732 for the full UI. `/api/*` routes are still handled by FastAPI.

## API Endpoints

All endpoints used by the frontend (defined in `loom/api_server.py`):

| Method | Path | Description |
|--------|------|-------------|
| GET | `/api/status` | Daemon status (polled every 5s) |
| GET | `/api/envelopes` | List envelopes (polled every 7s) |
| GET | `/api/envelopes/{id}` | Single envelope detail |
| POST | `/api/envelopes/{id}/approve` | Approve envelope |
| POST | `/api/envelopes/{id}/dismiss` | Dismiss envelope |
| GET | `/api/sources` | List sources with unread counts |

## Tech Stack

- **React 18** + **TypeScript**
- **Vite** — dev server & build tool
- **Tailwind CSS** — styling
- **shadcn/ui** (Radix UI) — component library
- **TanStack React Query** — data fetching & polling
- **react-markdown** + **remark-gfm** — Markdown rendering
- **Lucide** — icons
